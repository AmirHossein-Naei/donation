یک پروژه ساده با Flask برای جمع‌آوری حمایت‌های مالی کاربران. کاربران می‌تونن سریع، دونیشن بدن و این
دونیشن‌ها به‌صورت زنده در یک اورلی برای OBS نمایش داده می‌شن. مناسب برای استریم‌ها، رویدادهای آنلاین و جمع‌آوری حمایت از
محتوا.

# توجه
در هنگام اجرای پروژه، لطفاً تعداد workers در تنظیمات Gunicorn را روی یک تنظیم نمایید. دلیل این امر آن است که برخی اطلاعات Login در حال حاضر در متغیرهای حافظه موقت ذخیره می‌شوند؛ بنابراین، فعال‌سازی چندین Worker باعث ایجاد تداخل داده‌ها و بروز خطا خواهد شد.
